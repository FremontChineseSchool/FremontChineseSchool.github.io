# old_website/ — reference archive of the legacy Joomla site

These are HTML pages manually copied from the old Fremont Chinese School site
(fremontchineseschool.org, built in Joomla). They are kept **for reference
only** while we rebuild a new site — they are not served or linked together.

**Note on links:** internal links inside these files are absolute URLs to the
live old domain (`https://fremontchineseschool.org/...`), plus many dead
`goo.gl`/`bit.ly` shorteners. They are intentionally left as-is — the original
URL is self-documenting and more useful for reference than a relative path.

Filenames were chosen to match each page's original Joomla SEF slug (derived
from the `active` menu item in each file and the on-page link structure).
